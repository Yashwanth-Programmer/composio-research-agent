Research agent & verification

The agent was implemented as a batch research workflow using Composio search tools with a Gemini model. For each app it was instructed to return a strict JSON object containing the requested fields and an evidence URL. The batch runner wrote one result per line and retried failures.

Agent

Search → structured extraction → JSONL output.

Human needed

Retry/review was required for records that initially failed parsing or timed out; the final 100-record output has no failed-record markers.

Runnable proof

python run_batch.py is the runnable trigger used by the workflow. No live deployment link is claimed here.

Verification & evidence

Every final record contains an evidence URL. The final dataset has exactly 100 unique app names and no remaining PARSE_FAILED, FAILED_ALL_RETRIES, or MAX_TURNS_EXCEEDED records.

Categories are joined from the supplied 100-app CSV by app name. No research result was manually rewritten for this analysis.
